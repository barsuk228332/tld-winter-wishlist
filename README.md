# Winter Wishlist

Спавнер предметов для **The Long Dark**: окно со списком всех предметов игры,
включая добавленные модами, с иконками, поиском и настройкой количества/состояния.

![version](https://img.shields.io/badge/version-0.1.0-blue)
![game](https://img.shields.io/badge/The%20Long%20Dark-2.55-green)
![license](https://img.shields.io/badge/license-MIT-lightgrey)

## Что умеет

- **F7** — открыть/закрыть окно.
- Список всех предметов, которые знает сама игра: ваниль, DLC и предметы из
  установленных модов (игра регистрирует их в своём реестре, поэтому список
  полный — в тестовой сборке с 40+ модами нашлось 908).
- **Иконки** предметов в списке (берутся из иконок инвентаря игры).
- **Поиск** по названию на языке игры и по внутреннему ID: `нож`, `knife`,
  `GEAR_Knife` — всё найдёт охотничий нож.
- **Количество** (1–50) и **состояние** (0–100%).
- Спавн **в инвентарь** или **под ноги**.
- Названия на языке игры (RU/EN и другие, что есть в игре).
- Список прокручивается, длинные списки не тормозят (рисуются только видимые строки).
- Мод не меняет формат сохранений: спавнятся обычные ванильные предметы.

## Требования

| Что | Версия |
|---|---|
| The Long Dark | 2.55 (IL2CPP, GOG/Steam) |
| MelonLoader | 0.7.x |
| .NET Desktop Runtime | 6.0 (x64) — нужен для IL2CPP-модов |

Мод проверялся на TLD 2.55 (build 181032) + MelonLoader 0.7.2 под Linux/Proton.
На других версиях игры работать не обязан: IL2CPP-патчи зависят от версии.

## Установка

1. Установите MelonLoader, если его ещё нет.
2. Скопируйте `WinterWishlist.dll` в папку `Mods/` рядом с `tld.exe`.
3. Запустите игру.
4. В игре нажмите **F7**.

Удаление: удалить `WinterWishlist.dll` из `Mods/`.

## Управление

| Клавиша / элемент | Действие |
|---|---|
| `F7` | открыть/закрыть окно |
| `Esc` | закрыть окно |
| ввод с клавиатуры | поиск (Backspace — стереть) |
| `✕` в строке поиска | очистить поиск |
| `⟳` в заголовке | пересобрать список предметов |
| клик по предмету | заспавнить с текущими настройками |
| ползунки внизу | количество и состояние |
| галочка «под ноги» | спавн на землю вместо инвентаря |

Настройки хранятся в `UserData/MelonPreferences.cfg`, секция `[WinterWishlist]`:
`Hotkey`, `WindowWidth`, `WindowHeight`.

## Сборка из исходников

Нужен .NET SDK 6.0 и установленная игра (из неё берутся IL2CPP-сборки).

```bash
dotnet build -c Release
# или с другим путём к игре:
dotnet build -c Release -p:GameDir=/path/to/TheLongDark
```

Готовый `WinterWishlist.dll` автоматически копируется в `Mods/` игры.
Путь по умолчанию: `$HOME/Games/TheLongDark`.

## Как это работает

- Список предметов берётся из игрового реестра автокомплита консоли
  (`ConsoleManager.m_SearchStringToGearNames`) — это те же имена, которые
  понимает ванильная команда `add`.
- Названия — через `GearItem.GetGearDisplayName(prefabName)`, поэтому сразу на
  языке игры.
- Иконки — `Utils.GetInventoryIconTextureFromPrefabName(prefabName)`, лениво,
  с ограниченным кешем (400 штук).
- Спавн — `PlayerManager.AddItemCONSOLE(...)` (инвентарь) и
  `PlayerManager.InstantiateItemAtPlayersFeet(...)` (на землю).
- Модовые предметы, зарегистрированные через ModComponent, дополнительно
  подхватываются из его бандлов, если они есть в реестре.

## Ограничения

- Мод привязан к версии игры 2.55. После обновления TLD возможны поломки —
  нужен пересбор/перепроверка.
- Пока окно открыто, игра продолжает получать ввод с клавиатуры (движение и
  горячие клавиши). Это ограничение IMGUI-окна поверх игры.
- Иконки некоторых служебных/нестандартных предметов могут отсутствовать.
- Названия модовых предметов зависят от локализации самого мода: если у мода
  нет русского перевода, будет английское название.
