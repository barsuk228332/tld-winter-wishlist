# Winter Wishlist

Читерский мод-панель для **The Long Dark**: выдача любых предметов игры (включая
модовые), прокачка навыков, бессмертие, бесконечная грузоподъёмность, раскрытие
карты, управление временем и погодой, лечение всех болезней.

## Что умеет

Окно открывается по **F7** и состоит из вкладок.

### Предметы

- Список всех предметов, которые знает сама игра: ваниль, DLC и предметы из
  установленных модов (игра регистрирует их в своём реестре, поэтому список
  полный — в тестовой сборке с 40+ модами нашлось 908).
- **Иконки** предметов в списке (берутся из иконок инвентаря игры).
- **Поиск** по названию на языке игры и по внутреннему ID: `нож`, `knife`,
  `GEAR_Knife` — всё найдёт охотничий нож.
- **Количество** (1–50) и **состояние** (0–100%).
- Спавн **в инвентарь** или **под ноги**.
- **Починить всё в инвентаре** — восстанавливает состояние всех ремонтируемых
  предметов.
- **Набор выживальщика** — спички, нож, топор, пила, лом, спальник, патроны,
  стрелы, бинты, обезболивающее, антибиотики, ремнабор, точильный камень, вода.

### Скиллы

- Все навыки, которые реально есть в игре (список берётся у самого
  `SkillsManager`, поэтому версия игры с другим набором навыков не ломает окно:
  в 2.55, например, `ToolRepair` больше не существует и просто не показывается).
- Текущий уровень и кнопка **MAX** для каждого навыка.
- Кнопка **прокачать всё** — ставит Master (5 уровень) каждому навыку.

### Игрок

- **Бессмертие** — неуязвимость, запрет смерти и игнор со стороны ИИ.
- **Держать здоровье**, **не голодать**, **не испытывать жажду**,
  **не уставать**, **не замерзать** — эффекты обновляются каждые 0,5 секунды.
- Разово: полное здоровье, восстановление голода/жажды/усталости/тепла.
- **Выдать лучшую одежду** — комплект в инвентарь (100 % состояние): балаклава,
  шерстяная шапка, походная парка ×2, рыбацкий свитер ×2, варежки из меха
  кролика, армейские штаны ×2, альпинистские носки ×2, лыжные ботинки и
  шерстяные подштанники ×2.

### Движение

- Бесконечный спринт.
- Бесконечная выносливость (полная шкала).
- Бесконечная грузоподъёмность (500 кг, исходное значение восстанавливается
  при выключении).
- Отключение растяжений и вывихов.
- **Полёт** (экспериментально, через игровой `FlyMode`).

### Мир

- Раскрыть туман текущего региона.
- Разблокировать карту текущего региона.
- Разблокировать и раскрыть все регионы (best-effort, по загруженным
  `ZoneSpecification`).
- Время суток: ползунок + кнопки «Рассвет / Полдень / Закат / Полночь».
- Погода: «Сделать тепло».

### Болезни

- Список активных болезней и травм (ожоги, кровотечение, перелом, гипотермия,
  обморожение, инфекция, отравление, дизентерия, паразиты, растяжения и т.д.).
- **Вылечить всё** — завершает все активные аффекшены.
- Постоянное подавление обморожения и гипотермии.

## Требования

| Что | Версия |
|---|---|
| The Long Dark | 2.55 (IL2CPP, GOG/Steam) |
| MelonLoader | 0.7.x |
| .NET Desktop Runtime | 6.0 (x64) — нужен для IL2CPP-модов |

Мод проверялся на TLD 2.55 (build 181032) + MelonLoader 0.7.2 под Linux/Proton.
На других версиях игры работать не обязан: IL2CPP-патчи зависят от версии.

## Установка

1. Установите MelonLoader, если его ещё нет.
2. Скопируйте `WinterWishlist.dll` в папку `Mods/` рядом с `tld.exe`.
3. Запустите игру.
4. В игре нажмите **F7**.

Удаление: удалить `WinterWishlist.dll` из `Mods/`.

## Управление

| Клавиша / элемент | Действие |
|---|---|
| `F7` | открыть/закрыть окно |
| `Esc` | закрыть окно |
| перетаскивание заголовка | переместить окно |
| угол внизу справа | изменить размер окна |
| ввод с клавиатуры (вкладка «Предметы») | поиск |
| `⟳` в заголовке | пересобрать список предметов |

Настройки хранятся в `UserData/MelonPreferences.cfg`, секция `[WinterWishlist]`:
`Hotkey`, `WindowWidth`, `WindowHeight`.

Читы не сохраняются между запусками: после перезапуска игры все переключатели
выключены. При выгрузке мода активные эффекты сбрасываются автоматически.

## Сборка из исходников

Нужен .NET SDK 6.0 и установленная игра (из неё берутся IL2CPP-сборки).

```bash
dotnet build -c Release
# или с другим путём к игре:
dotnet build -c Release -p:GameDir=/path/to/TheLongDark
```

Готовый `WinterWishlist.dll` автоматически копируется в `Mods/` игры.
Путь по умолчанию: `$HOME/Games/TheLongDark`.

## Как это работает

- Список предметов берётся из игрового реестра автокомплита консоли
  (`ConsoleManager.m_SearchStringToGearNames`) — это те же имена, которые
  понимает ванильная команда `add`.
- Названия — через `GearItem.GetGearDisplayName(prefabName)`, поэтому сразу на
  языке игры.
- Иконки — `Utils.GetInventoryIconTextureFromPrefabName(prefabName)`, лениво,
  с ограниченным кешем (400 штук).
- Спавн — `PlayerManager.AddItemCONSOLE(...)` (инвентарь) и
  `PlayerManager.InstantiateItemAtPlayersFeet(...)` (на землю).
- Модовые предметы, зарегистрированные через ModComponent, дополнительно
  подхватываются из его бандлов, если они есть в реестре.
- Скиллы — `SkillsManager.GetSkill(...)` + `Skill.SetTier/SetPoints(...)`.
- Читы выживания — компоненты `Condition`, `Fatigue`, `Hunger`, `Thirst`,
  `Freezing`, `PlayerMovement`, `Encumber`; поддерживающие эффекты
  переприменяются раз в 0,5 секунды.
- Карта — `Panel_Map.RevealCurrentScene()`, `UnlockMapCurrentScene()`,
  `UnlockRegionMap(...)`, `RevealFogForScene(...)`.
- Время и погода — `TimeOfDay.SetNormalizedTime(...)`, `Weather.WarmWeather()`.
- Болезни — соответствующие `*End()`/`Cure()` методы компонентов аффекшенов.

## Ограничения

- Мод привязан к версии игры 2.55. После обновления TLD возможны поломки —
  нужен пересбор/перепроверка.
- Полёт помечен как экспериментальный: при включении/выключении камера может
  вести себя неожиданно, сохранитесь заранее.
- Раскрытие всех регионов работает по уже загруженным `ZoneSpecification`;
  если часть регионов не подгружена, сначала откройте карту мира.
- Иконки некоторых служебных/нестандартных предметов могут отсутствовать.
- Названия модовых предметов зависят от локализации самого мода: если у мода
  нет русского перевода, будет английское название.
